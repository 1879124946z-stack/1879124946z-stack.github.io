# 伦敦塔（climb-tol-1.0.0）

- 构念：计划性问题解决，兼顾规则维持与执行效率。
- 材料：红、蓝、黄3个球；三根柱容量依次为3、2、1。
- 规则：一次只能移动一根柱子最上面的球，且不能超过目标柱容量。
- 正式结构：12题，最短解为2、3、4、5步的题目各3题，分2组。
- 等值形式：按儿童编号在A/B式间平衡；后测自动使用与前测相反的形式。
- 每题上限：20次移动或120秒。
- 主要因变量：完美解率、解决率、首次移动前计划时间、执行时间、多余步数与规则违反。

未解决题的多余步数留空，不应按0处理。首次移动前计划时间较长不必然代表更差，应与完美解率和多余步数联合解释。
