# 儿童箭头 Flanker（climb-flanker-1.1.0）

- 构念：抑制控制与选择性注意。
- 正式结构：50题，分2组；一致/不一致条件及左右反应数量之差不超过1题。
- 时序：注视点500 ms；刺激最长2500 ms；试次间隔500–800 ms。
- 练习：8题，正确率达到75%进入正式测试，最多练习2轮。
- 主要因变量：正确率、正确反应时中位数、反应时干扰效应、不一致正确率下降、反应时变异。
- 清洗建议：仅将正确且200–2500 ms的反应纳入反应时分析；正确率保留全部正式试次。

正式测试不向儿童反馈得分。平台会自动附加匿名编号、前/后测、年龄、性别、设备与测试员字段。
