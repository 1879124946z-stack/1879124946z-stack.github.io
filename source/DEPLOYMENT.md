# 认知实验网站：交付与上线说明

2026-09-07：已完成服务器版本改造和本机验证，**尚未发布到公网**。原来的 chatgpt.site 地址仍是原版本。本次没有向境外平台上传学生信息、实验数据或服务器私钥，也没有开通付费服务。

## 使用方式

- 学生入口 `/`：输入学号、整数周岁、男/女、三年级/四年级。已有学号的其他信息必须一致。
- 管理员入口 `/admin`：账号密码登录，查看登记学生与各项目完成状态、修改年龄/性别/年级、删除学生或项目数据、查看和下载 CSV。
- 五个项目的题目、刺激、流程和计分算法保留。DCCS 的结束页移除了成绩和下载；练习反馈仍按原流程保留。
- 学生自由选择下一个项目；同一学号每个项目只保存最近一次完整数据。未完成的新测试没有逐试次落盘，不覆盖旧数据。
- 同学号同项目的并行测试在服务器上拒绝。长时间断网时锁不会自动过期，以免第二台设备进入并覆盖；异常关闭后可由老师在后台“释放占用”。释放会作废未提交尝试，但保留已有完整结果。
- 已加载的测试无需网络运行。完整结果使用 AES-GCM 加密，密钥用服务器 RSA-OAEP 公钥封装，暂存在浏览器待发送区；恢复网络后每15秒重试，成功后移除。只有服务器持有解密私钥。
- 断网后不要清除浏览器数据；如果浏览器不允许暂存，必须保持完成页面打开。关闭未完成项目后重新进入会从头开始。

## CSV 规则

每个项目生成自己的 `项目_raw.csv` 与 `项目_summary.csv`，绝不跨项目合表。批量下载 ZIP 内按项目分目录，每个目录两份 CSV。

- `raw`：逐试次完整字段、嵌套行为/事件数据（JSON）、学生信息、项目/尝试标识、开始/结束/接收时间、设备信息、测试时登记快照。
- `summary`：每位学生一行，全部原有汇总字段及上述元数据。
- 学号按自然顺序排序，纯文本保存开头的0。CSV为UTF-8 BOM；在 Excel 中用“从文本/CSV”导入，并将 `student_id` 列设为文本，避免 Excel 自行去掉0。
- 修正后的年龄、性别和年级出现在元数据列；原始试次与测试时快照保持原样，避免改写已经采集的原始内容。
- 公式样式的文本前置单引号以避免电子表格公式执行。
- 旧站浏览器中的历史记录没有自动迁移；本次服务器数据库从空库开始。

## 本机启动

需要 Node.js 24（使用内置 SQLite）和项目已有 pnpm。首次：

```powershell
pnpm setup:mainland
pnpm dev:mainland
```

打开终端打印的本机地址；默认学生端 `http://localhost:3000/`，后台 `http://localhost:3000/admin`。

首次初始化会生成随机管理员密码和内部服务密钥，保存在私有 `.data` 目录。管理员登录信息在 `.data/管理员登录信息.txt`。没有通用默认密码，不将密码写入网页或代码。

生产构建与启动：

```powershell
pnpm build:mainland
pnpm start:mainland
```

也可使用交付 ZIP：解压到私有目录，安装 Node.js 24，运行 `node server/manage.mjs` 和 `node server/run.mjs`。该方式不需要再次下载前端依赖。应在目标操作系统验证；若平台不兼容，使用源码在目标服务器构建。

## 中国大陆服务器部署

必须先有满足要求的境内服务器/平台及可用HTTPS地址，再正式开放。本次仅制作部署材料，没有购买或配置云账号。

单台常驻服务器运行前端与数据服务，数据库存放该机器的持久磁盘。后端只监听 `127.0.0.1:8788`，不对外开放；前端统一通过 `/api` 转发。不得放在会回收磁盘的临时函数实例上，不支持多个独立SQLite副本横向扩容。

部署时设置：

```text
LAB_PUBLIC_ORIGIN=https://你的实际网站域名
LAB_SECURE_COOKIES=1
LAB_DATA_DIR=/网站公开目录之外的持久数据目录
HOST=127.0.0.1
PORT=3000
```

`LAB_DATA_DIR` 必须在初始化和启动时保持一致。内部服务密钥从该目录的 runtime.json 读取。若更改后端端口，设置 LAB_API_PORT；启动脚本自动配置对应的 LAB_API_URL。

将HTTPS反向代理指向前端3000端口，保持请求Host；配置精确的LAB_PUBLIC_ORIGIN。代理仅转发应用，不映射项目根目录或 `.data`；上传上限8MB，超时至少30秒。登录Cookie设为HttpOnly、SameSite=Strict，公网必须Secure。

样例 `deploy/nginx.conf.example` 需要填入真实域名和证书位置，不能原样用于上线。

## 数据长期保存与维护

没有数据自动过期或定期删除功能。会话和登录限流记录按有效期清理，实验结果不会随之清理。

```powershell
node server/manage.mjs --backup
node server/manage.mjs --reset-admin
```

前者使用SQLite在线备份接口生成一致的数据库副本，后者重置管理员密码并使旧后台会话失效。备份放在私有 `.data` 目录；管理员需另存到受控的境内备份位置。数据库、encryption-key.json 和 runtime.json 都需保护；恢复时要恢复对应的解密密钥，才能接收已经加密但尚未发送的记录。

## 托管平台核实

“免费提供子域名”和“永久免费保存研究数据、境内存储、80人并发”不是同一承诺。截至2026-09-07，没有核实到同时满足全部条件并可立即使用的方案。

| 候选 | 官方提供什么 | 本项目尚缺什么 |
|---|---|---|
| 腾讯云 CloudBase | 静态网站托管及默认域名，配套后端能力 | 当前新环境是免费体验方案，不能视为长期免费；默认域名有使用策略限制 |
| 阿里云函数计算 | 新用户试用资源，可以部署Web应用 | 免费有期限/额度；生产网站域名需按官方指引配置，持久数据库也需独立安排 |
| 腾讯 EdgeOne Pages / Makers | 长期有效的免费版，平台子域名，云函数和KV/Blob能力 | 官方材料未明确证明本项目数据及副本全部境内、强一致占用锁和长期容量均有免费保障；需要账号内配置与存储地域进一步核实，不能直接承诺符合要求 |
